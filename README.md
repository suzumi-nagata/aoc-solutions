# Advent of Code Solutions

Hi there, this is a repo to store my solutions for the advent of code (aoc) programming
challenges.

As requested by the creator of aoc, to avoid leaking the inputs from the site, I'm storing
the inputs on a private git submodule.

Note to myself as I should have the proper access to the private repo, is to initialize
them:

```bash
git submodule init
git submodule update
```

The submodule is just a list of inputs on the format:

```text
aoc-inputs/
└── <year>
    └── day01
    └── day02
    └── ...
```
